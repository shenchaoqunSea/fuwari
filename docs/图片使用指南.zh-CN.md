# 博客图片使用指南

本文档介绍如何在 Fuwari 博客中管理和使用图片。

---

## 📁 图片存放位置

### 1. 文章专用图片（推荐）

将图片放在文章同目录下，便于管理：

```
src/content/posts/
├── 设计模式/
│   ├── Builder 模式.md
│   ├── cover.png           # 文章封面
│   └── images/             # 文章内图片
│       ├── diagram-1.png
│       └── diagram-2.png
├── Android/
│   ├── Kotlin 基础.md
│   └── kotlin-logo.jpg
```

**在 front-matter 中引用封面**：
```yaml
---
title: Builder 模式完全指南
image: "./cover.png"    # 相对于当前文章目录
---
```

**在文章内容中引用图片**：
```markdown
![架构图](./images/diagram-1.png)

![流程图](./images/diagram-2.png)
```

---

### 2. 全局资源图片

用于全局配置的资源（头像、logo 等）：

```
src/assets/images/
├── logo.jpg
├── avatar.png
└── banner.png
```

**在 `src/config.ts` 中引用**：
```typescript
export const profileConfig: ProfileConfig = {
  avatar: "assets/images/logo.jpg",  // 相对于 /src 目录
  // ...
};

export const siteConfig: SiteConfig = {
  banner: {
    src: "assets/images/banner.png",  // 相对于 /src 目录
    // 如果以 '/' 开头则是相对于 /public 目录
  },
  // ...
};
```

---

### 3. 静态资源图片

用于公开访问的静态资源：

```
public/
├── images/
│   ├── screenshot.png
│   └── diagram.jpg
└── favicon/
    └── icon.png
```

**在 Markdown 中引用**：
```markdown
![截图](/images/screenshot.png)  # 以 / 开头，相对于 public
```

---

## 📝 在文章中插入图片

### 方法一：标准 Markdown 语法

```markdown
![图片说明](./images/diagram.png)

![远程图片](https://example.com/image.png)
```

### 方法二：HTML 语法（更灵活）

```markdown
<img src="./diagram.png" alt="说明" style="width: 80%">

<img src="https://example.com/image.png" width="500">
```

### 方法三：带标题的图片

```markdown
![图片说明](./diagram.png)
*图 1：系统架构图*
```

## 🎯 推荐做法

| 图片类型 | 存放位置 | 引用方式 | 示例 |
|---------|---------|---------|------|
| 文章封面图 | 文章同目录 | `image: "./cover.png"` | front-matter |
| 文章内图片 | 文章同目录/images/ | `![alt](./images/pic.png)` | Markdown |
| 全局头像 | `src/assets/images/` | `assets/images/logo.jpg` | config.ts |
| 通用资源 | `public/images/` | `/images/file.png` | Markdown |
| 外部图片 | - | `https://...` | 直接 URL |

## 💡 最佳实践

1. **文件命名**：使用小写字母和连字符，如 `builder-pattern.png`
2. **图片格式**：优先使用 WebP 格式（体积小，质量高）
3. **图片大小**：压缩图片，单张建议不超过 500KB
4. **目录组织**：每篇文章建立独立文件夹，便于管理
5. **相对路径**：文章内图片使用相对路径，便于迁移

## 🔧 常见问题

### Q：图片不显示怎么办？

1. 检查文件路径是否正确
2. 确认图片文件确实存在
3. 重新构建项目：`pnpm build`

### Q：图片太大怎么办？

使用在线工具压缩图片：
- [TinyPNG](https://tinypng.com/)
- [Squoosh](https://squoosh.app/)

### Q：如何设置图片大小？

```markdown
<!-- HTML 方式 -->
<img src="./image.png" width="500">

<!-- 或使用 style -->
<img src="./image.png" style="width: 80%; max-width: 600px">
```
