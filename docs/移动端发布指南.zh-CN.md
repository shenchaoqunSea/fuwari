# 移动端发布指南

本博客支持移动端直接发布文章，无需打开电脑。

## 📱 使用方法

### 1. 获取 GitHub Token

1. 访问 https://github.com/settings/tokens
2. 点击 "Generate new token (classic)"
3. 勾选 `repo` 权限（完整的仓库访问权限）
4. 生成并复制 Token

### 2. 打开发布页面

在手机浏览器访问：

```
https://shenchaoqunsea.github.io/fuwari/admin/publish
```

### 3. 输入 Token

首次使用时输入 GitHub Token，Token 会保存在浏览器本地，无需重复输入。

### 4. 写作并发布

- **文章类型**：选择"朋友圈"或"普通文章"
- **标题**：输入文章标题
- **标签**：（普通文章可选）用逗号分隔
- **图片**：点击"选择图片"按钮上传（支持多图）
- **内容**：支持 Markdown 语法

点击"发布"按钮，文章和图片会自动提交到 GitHub，GitHub Actions 会自动构建并发布。

|------|---------|---------|

## 📷 图片上传

### 图片来源

| 来源 | 说明 |
|------|------|
| **🖼️ 相册** | 从手机相册选择照片（支持多选）|
| **📷 拍照** | 直接调用相机拍照 |

### 功能特点

- ✅ 支持多图选择
- ✅ 实时预览，可删除重选
- ✅ 自动验证文件类型和大小（限制 5MB）
- ✅ 第一张图片自动设置为封面
- ✅ 图片使用相对路径 `./images/文件名`
- ✅ 触摸优化，防止误操作

## 🔒 安全说明

- Token 保存在浏览器 localStorage 中
- 请勿在公共设备上保存 Token
- 定期更换 Token 保障安全
- Token 只有 `repo` 权限，无法访问其他 GitHub 功能
